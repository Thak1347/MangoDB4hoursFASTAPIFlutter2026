# Part 1 — Introduction to CRUD (5 minutes)

CRUD represents the four fundamental operations for working with stored data.

| Operation | Purpose | MongoDB methods |
|---|---|---|
| Create | Insert new documents | `insertOne()`, `insertMany()` |
| Read | Retrieve documents | `find()`, `findOne()` |
| Update | Modify existing documents | `updateOne()`, `updateMany()` |
| Delete | Remove documents | `deleteOne()`, `deleteMany()` |

For example, in a student management system:

- Create: register a new student.
- Read: display student information.
- Update: change a student's academic year.
- Delete: remove a student record when deletion is authorized.

## Connect to your database

Open MongoDB Shell (`mongosh`) and run:

```javascript
use university_db
```

Check the existing student records:

```javascript
db.students.find({})
```

If your collection is empty, complete the setup in Part 2 before continuing.

# Part 2 — CREATE: Insert Documents (10 minutes)

The Create operation adds documents to a collection.

## 2.1 Insert one document

Use `insertOne()` to insert a single student.

```javascript
db.students.insertOne({
  student_code: "ST006",
  name: "Maly",
  age: 22,
  major: "Software Development",
  year: 4,
  is_active: true
})
```

Example result:

```javascript
{
  acknowledged: true,
  insertedId: ObjectId("...")
}
```

The actual `insertedId` is generated by MongoDB.

## 2.2 Insert multiple documents

Use `insertMany()` when you want to add multiple records in one operation.

```javascript
db.students.insertMany([
  {
    student_code: "ST007",
    name: "Kanha",
    age: 19,
    major: "Computer Science",
    year: 1,
    is_active: true
  },
  {
    student_code: "ST008",
    name: "Sokha",
    age: 21,
    major: "Information Technology",
    year: 3,
    is_active: true
  },
  {
    student_code: "ST009",
    name: "Dalin",
    age: 20,
    major: "Software Development",
    year: 2,
    is_active: false
  }
])
```

## 2.3 Verify inserted records

```javascript
db.students.find({})
```

Count the documents:

```javascript
db.students.countDocuments({})
```

**Important:** `student_code` is an application-defined field. MongoDB does not automatically enforce its uniqueness. If each student must have a unique student code, create a unique index:

```javascript
db.students.createIndex(
  { student_code: 1 },
  { unique: true }
)
```

Create this index only after checking that existing documents do not contain duplicate student codes.

# Part 3 — READ: Retrieve Documents (10 minutes)

The Read operation retrieves documents from a collection.

## 3.1 Retrieve all documents

```javascript
db.students.find({})
```

The empty filter `{}` matches every document in the collection.

## 3.2 Retrieve one document

```javascript
db.students.findOne({
  student_code: "ST001"
})
```

`findOne()` returns the first matching document or `null` if no document matches.

## 3.3 Filter by an exact value

Find students whose major is Software Development:

```javascript
db.students.find({
  major: "Software Development"
})
```

Find students in academic year 2:

```javascript
db.students.find({
  year: 2
})
```

Find inactive students:

```javascript
db.students.find({
  is_active: false
})
```

## 3.4 Return selected fields with projection

Projection controls which fields are returned.

```javascript
db.students.find(
  { major: "Software Development" },
  { name: 1, student_code: 1, major: 1, _id: 0 }
)
```

This returns only the specified fields and excludes `_id`.

By default, `_id` is included unless explicitly excluded.

## 3.5 Sort and limit results

Sort students by age in ascending order:

```javascript
db.students.find({}).sort({ age: 1 })
```

Sort students by age in descending order:

```javascript
db.students.find({}).sort({ age: -1 })
```

Return only the first three results:

```javascript
db.students.find({}).limit(3)
```

You can combine these methods:

```javascript
db.students.find({})
  .sort({ age: -1 })
  .limit(3)
```

This returns up to three of the oldest students. For consistent ordering when ages are equal, add a secondary sort field.

# Part 4 — Query Filters and Operators (10 minutes)

Query filters specify which documents MongoDB should match.

## 4.1 Comparison operators

| Operator | Meaning | Example |
|---|---|---|
| `$gt` | Greater than | `{ age: { $gt: 20 } }` |
| `$gte` | Greater than or equal to | `{ age: { $gte: 20 } }` |
| `$lt` | Less than | `{ age: { $lt: 20 } }` |
| `$lte` | Less than or equal to | `{ age: { $lte: 20 } }` |
| `$ne` | Not equal to | `{ year: { $ne: 2 } }` |
| `$eq` | Equal to | `{ year: { $eq: 2 } }` |
| `$in` | Matches any listed value | `{ year: { $in: [1, 2] } }` |
| `$nin` | Matches none of the listed values | `{ year: { $nin: [1, 2] } }` |

### Example 1: Students older than 20

```javascript
db.students.find({
  age: { $gt: 20 }
})
```

### Example 2: Students aged 20 or older

```javascript
db.students.find({
  age: { $gte: 20 }
})
```

### Example 3: Students younger than 21

```javascript
db.students.find({
  age: { $lt: 21 }
})
```

### Example 4: Students who are not in year 2

```javascript
db.students.find({
  year: { $ne: 2 }
})
```

Note that `$ne` can also match documents where the field is missing. If the field must exist, include an `$exists` condition.

### Example 5: Students in year 1 or year 2

```javascript
db.students.find({
  year: { $in: [1, 2] }
})
```

## 4.2 AND conditions

MongoDB implicitly combines different field conditions with AND when they appear in the same filter.

Find active students aged 20 or older:

```javascript
db.students.find({
  age: { $gte: 20 },
  is_active: true
})
```

Both conditions must match.

The explicit `$and` operator is available when needed:

```javascript
db.students.find({
  $and: [
    { age: { $gte: 20 } },
    { is_active: true }
  ]
})
```

For straightforward conditions on different fields, the implicit AND form is usually simpler.

## 4.3 OR conditions

Use `$or` when at least one condition must match.

Find students in year 1 or year 4:

```javascript
db.students.find({
  $or: [
    { year: 1 },
    { year: 4 }
  ]
})
```

Find students who are either older than 21 or inactive:

```javascript
db.students.find({
  $or: [
    { age: { $gt: 21 } },
    { is_active: false }
  ]
})
```

## 4.4 Combine AND and OR

Find active students who are either in year 1 or older than 21:

```javascript
db.students.find({
  is_active: true,
  $or: [
    { year: 1 },
    { age: { $gt: 21 } }
  ]
})
```

The logic is:

```text
is_active = true
AND
(year = 1 OR age > 21)
```

# Part 5 — UPDATE: Modify Documents (10 minutes)

The Update operation changes existing documents.

MongoDB supports `updateOne()` for one matching document and `updateMany()` for multiple matching documents.

## 5.1 Update one document using `$set`

Change ST006's academic year to 3:

```javascript
db.students.updateOne(
  { student_code: "ST006" },
  { $set: { year: 3 } }
)
```

Example result:

```javascript
{
  acknowledged: true,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}
```

Meaning:

- `matchedCount`: number of documents matching the filter.
- `modifiedCount`: number of documents actually changed.
- `upsertedCount`: number of documents inserted through upsert behavior.

If the document already has `year: 3`, the matched count can be 1 while the modified count is 0.

## 5.2 Update multiple documents

Set all inactive students to year 1:

```javascript
db.students.updateMany(
  { is_active: false },
  { $set: { year: 1 } }
)
```

Every matching document is updated.

## 5.3 Update multiple fields

Update ST006's age and major:

```javascript
db.students.updateOne(
  { student_code: "ST006" },
  {
    $set: {
      age: 23,
      major: "Information Technology"
    }
  }
)
```

Only the specified fields are changed. Other fields remain unchanged.

## 5.4 Increment a numeric value

Use `$inc` to increase a numeric field.

Increase the academic year of ST006 by one:

```javascript
db.students.updateOne(
  { student_code: "ST006" },
  { $inc: { year: 1 } }
)
```

For example, a student in year 3 becomes year 4.

## 5.5 Understand PUT versus PATCH

When building a REST API, you may use:

- **PUT:** Usually represents replacing a resource's state with the supplied representation.
- **PATCH:** Usually represents applying a partial update.

In MongoDB, `$set` updates only the specified fields.

For example:

```javascript
db.students.updateOne(
  { student_code: "ST006" },
  { $set: { age: 24 } }
)
```

This changes only `age`; it does not replace the entire document.

**Important:** HTTP PUT and PATCH semantics are determined by your API implementation. MongoDB's `updateOne()` is not itself an HTTP PUT or PATCH operation.

## 5.6 Verify the update

```javascript
db.students.findOne({
  student_code: "ST006"
})
```

Always check the updated document when practicing data modification.

# Part 6 — DELETE: Remove Documents (5 minutes)

The Delete operation removes documents from a collection.

**Warning:** Delete operations can permanently remove data. Inspect the filter and matching documents before executing a deletion.

## 6.1 Delete one document

Example using a practice record:

```javascript
db.students.deleteOne({
  student_code: "ST009"
})
```

This deletes at most one matching document.

If `student_code` is not unique, the first matching document may not be the one you intended. A unique index or a unique `_id` filter is safer.

## 6.2 Delete multiple documents

Delete all inactive student records:

```javascript
db.students.deleteMany({
  is_active: false
})
```

This removes every matching document. Use this only when deletion of all matching records is intended.

## 6.3 Check before deleting

First, inspect the documents:

```javascript
db.students.find({
  student_code: "ST009"
})
```

Count the matches:

```javascript
db.students.countDocuments({
  student_code: "ST009"
})
```

Then delete only if the result is correct.

## 6.4 Important safety rule

Avoid running this command unless you deliberately intend to empty the collection:

```javascript
db.students.deleteMany({})
```

The empty filter `{}` matches all documents.

For a real student management system, consider whether records should be deactivated or archived instead of physically deleted, especially when academic records must be retained.

# Key Takeaways

1. CRUD means Create, Read, Update, and Delete.
2. Use `insertOne()` or `insertMany()` to create documents.
3. Use `find()` and `findOne()` to retrieve documents.
4. Query filters select which documents match.
5. Comparison operators include `$gt`, `$gte`, `$lt`, `$lte`, and `$ne`.
6. Use `$in` to match one of several values.
7. MongoDB implicitly combines conditions on different fields using AND; `$or` matches at least one alternative.
8. Use `$set` to change specific fields and `$inc` to change numeric values.
9. Use `updateOne()` for one matching document and `updateMany()` for multiple documents.
10. Inspect filters before executing delete operations.

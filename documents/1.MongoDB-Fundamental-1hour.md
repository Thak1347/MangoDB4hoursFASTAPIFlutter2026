# Part 1 — Introduction to MongoDB (10 minutes)

## 1.1 What is MongoDB?

MongoDB is a NoSQL database management system that stores data in flexible, JSON-like documents.

It is commonly used in applications such as:

- Student management systems
- E-commerce platforms
- Social media applications
- Inventory management systems
- Mobile and web applications

For example, a university application might store student information, including student codes, names, ages, majors, and academic years.

## 1.2 Why use MongoDB?

MongoDB offers several useful features:

- **Flexible schema:** Documents in the same collection can have different fields.
- **Document-based storage:** Related information can be grouped in one document.
- **Query support:** Retrieve documents using filters and conditions.
- **Scalability:** MongoDB supports deployment patterns designed for growing applications.
- **Application integration:** Drivers are available for languages such as JavaScript, Python, Java, and PHP.

## 1.3 What is NoSQL?

NoSQL refers to database systems that use data models beyond the traditional relational-table model.

Common NoSQL database categories include:

- Document databases
- Key-value databases
- Wide-column databases
- Graph databases

MongoDB is a **document database**.

# Part 2 — MongoDB Data Structure (10 minutes)

MongoDB organizes data using databases, collections, documents, and fields.

## 2.1 Database

A database contains collections.

Example:

`university_db`

This database will store information for a university student management application.

## 2.2 Collection

A collection contains related documents.

Example:

`students`

A students collection stores student records.

A collection is broadly comparable to a table in a relational database.

## 2.3 Document

A document represents one record. Documents use a JSON-like structure consisting of fields and values.

Example:

```json
{
  "student_code": "ST001",
  "name": "Dara",
  "age": 20,
  "major": "Software Development",
  "year": 2,
  "is_active": true
}
```

This document represents one student.

## 2.4 Fields and values

| Field | Example value | Data type |
|---|---|---|
| `student_code` | `"ST001"` | String |
| `name` | `"Dara"` | String |
| `age` | `20` | Number |
| `major` | `"Software Development"` | String |
| `year` | `2` | Number |
| `is_active` | `true` | Boolean |

MongoDB also supports arrays, nested documents, dates, ObjectIds, and other BSON types.

## 2.5 MongoDB hierarchy

```text
university_db
└── students
    ├── Document 1: ST001
    │   ├── student_code
    │   ├── name
    │   ├── age
    │   └── major
    ├── Document 2: ST002
    └── Document 3: ST003
```

Remember:

- Database → contains collections
- Collection → contains documents
- Document → contains fields and values

# Part 3 — MongoDB vs. SQL and BSON (10 minutes)

## 3.1 MongoDB vs. relational databases

| Concept | MongoDB | SQL database |
|---|---|---|
| Data organization | Documents | Tables |
| Record | Document | Row |
| Attribute | Field | Column |
| Group of records | Collection | Table |
| Typical structure | Flexible documents | Defined relational schema |
| Query example | MongoDB query API | SQL statements |

MongoDB and SQL databases can both support reliable application data storage. The appropriate choice depends on the application’s data model, query patterns, consistency requirements, and operational needs.

## 3.2 SQL example

A relational table might contain:

| student_code | name | age |
|---|---|---:|
| ST001 | Dara | 20 |
| ST002 | Lina | 19 |

A SQL query to retrieve all students:

```sql
SELECT * FROM students;
```

## 3.3 MongoDB example

MongoDB stores similar information as documents:

```javascript
{
  student_code: "ST001",
  name: "Dara",
  age: 20
}
```

Retrieve all students:

```javascript
db.students.find({})
```

The empty filter `{}` matches all documents in the collection.

## 3.4 What is BSON?

BSON means **Binary JSON**. It is MongoDB's binary-encoded document format.

It supports data types such as:

- Strings
- Integers and floating-point numbers
- Booleans
- Dates
- Arrays
- Embedded documents
- ObjectIds

MongoDB automatically generates an `_id` field for a document when one is not supplied.

Example:

```javascript
{
  _id: ObjectId("..."),
  student_code: "ST001",
  name: "Dara"
}
```

The displayed ObjectId is an example placeholder, not a real identifier.

# Part 4 — Environment Setup (10 minutes)

You can use either MongoDB Compass with a local MongoDB server or MongoDB Atlas in the cloud.

## Option A: MongoDB Compass

MongoDB Compass provides a graphical interface for viewing databases, collections, and documents.

1. Download Compass: https://www.mongodb.com/products/tools/compass
2. Install and open it.
3. Connect to your MongoDB server.
4. View or create databases and collections.

**Note:** Compass is a graphical client. A local MongoDB server must be installed and running if you want to use a local database.

## Option B: MongoDB Atlas

MongoDB Atlas provides a cloud-hosted MongoDB database.

1. Create an account: https://www.mongodb.com/cloud/atlas/register
2. Create a cluster or database deployment.
3. Configure database access.
4. Configure network access.
5. Obtain the connection string.
6. Connect using Compass or your application's MongoDB driver.

Do not publish database passwords or private connection strings in a public repository.

## Verify your environment

If MongoDB Shell (`mongosh`) is installed and connected, run:

```javascript
db.runCommand({ ping: 1 })
```

A successful response includes:

```javascript
{ ok: 1 }
```

# Part 5 — Hands-on Practice (15 minutes)

**Goal:** Create a database and insert and retrieve student records.

Use MongoDB Shell (`mongosh`).

## Step 1: Select a database

```javascript
use university_db
```

This switches to `university_db`. The database is generally persisted when data is first stored in it.

## Step 2: Insert one student

```javascript
db.students.insertOne({
  student_code: "ST001",
  name: "Dara",
  age: 20,
  major: "Software Development",
  year: 2,
  is_active: true
})
```

Expected result: a successful acknowledgement and an inserted identifier.

## Step 3: Insert multiple students

```javascript
db.students.insertMany([
  {
    student_code: "ST002",
    name: "Lina",
    age: 19,
    major: "Computer Science",
    year: 1,
    is_active: true
  },
  {
    student_code: "ST003",
    name: "Vannak",
    age: 21,
    major: "Software Development",
    year: 3,
    is_active: true
  },
  {
    student_code: "ST004",
    name: "Sophea",
    age: 20,
    major: "Information Technology",
    year: 2,
    is_active: true
  }
])
```

## Step 4: Retrieve all students

```javascript
db.students.find({})
```

To display results in a more readable format:

```javascript
db.students.find({}).pretty()
```

## Step 5: Retrieve one student

```javascript
db.students.findOne({
  student_code: "ST001"
})
```

This returns the first matching document or `null` if no document matches.

## Step 6: Retrieve students by major

```javascript
db.students.find({
  major: "Software Development"
})
```

This returns documents whose `major` field matches the specified value.

## Step 7: Count students

```javascript
db.students.countDocuments({})
```

This counts all documents in the collection.

## Step 8: List databases and collections

List databases:

```javascript
show dbs
```

List collections in the current database:

```javascript
show collections
```

## Quiz

**Question 1:** What is a collection in MongoDB?

A. A single field  
B. A group of documents  
C. A database server

**Question 2:** What format does MongoDB use internally for document storage?

A. HTML  
B. BSON-JSON  
C. CSV only

**Question 3:** Which command retrieves all documents from the students collection?

A. `db.students.insertOne({})`  
B. `db.students.find({})`  
C. `db.students.deleteOne({})`

**Question 4:** What does `_id` identify?

A. A document  
B. A database server  
C. A collection only

**Question 5:** What does the following command do?

```javascript
db.students.find({ year: 2 })
```

A. Deletes year 2 students  
B. Retrieves documents where `year` equals `2`  
C. Changes all students to year 2

## Answer key

1. B — A collection groups documents.
2. B — MongoDB uses BSON.
3. B — `find({})` matches all documents.
4. A — `_id` uniquely identifies a document within its collection.
5. B — The filter matches documents with `year` equal to `2`.

# Part 1 — Understand the Architecture (10 minutes)

## 1.1 How does Flutter communicate with FastAPI?

Flutter sends an HTTP request to the FastAPI backend. FastAPI queries MongoDB and returns a JSON response.

```text
Flutter Application
       |
       | HTTP GET /students
       v
FastAPI Backend
       |
       | MongoDB query
       v
MongoDB Database
       |
       | Student documents
       v
FastAPI converts documents to JSON
       |
       | HTTP 200 + JSON response
       v
Flutter parses JSON into Dart objects
       |
       v
ListView displays student records
```

Each component has a specific responsibility:

| Component | Responsibility |
|---|---|
| Flutter UI | Displays student information |
| API service | Sends HTTP requests |
| Dart model | Represents student data |
| FastAPI | Validates requests and implements API logic |
| MongoDB | Stores student documents |

## 1.2 Example API response

When Flutter requests `GET /students`, FastAPI returns a JSON array similar to this:

```json
[
  {
    "_id": {
      "$oid": "671234567890abcdef123456"
    },
    "student_code": "ST001",
    "name": "Dara",
    "age": 20,
    "major": "Software Development",
    "year": 2,
    "is_active": true
  },
  {
    "_id": {
      "$oid": "671234567890abcdef123457"
    },
    "student_code": "ST002",
    "name": "Lina",
    "age": 19,
    "major": "Computer Science",
    "year": 1,
    "is_active": true
  }
]
```

The `_id` representation shown above is possible when MongoDB-specific JSON serialization is used. In your FastAPI code from Hour 3, `json_util` can produce this Extended JSON structure.

However, for a mobile application, it is often simpler to convert `_id` into a plain string on the backend:

```json
{
  "id": "671234567890abcdef123456",
  "student_code": "ST001",
  "name": "Dara",
  "age": 20,
  "major": "Software Development",
  "year": 2,
  "is_active": true
}
```

For this lesson, Flutter will read the student fields and ignore `_id`. The model can be extended to support either ID representation later.

## 2.4 Set the correct API base URL

The correct URL depends on where Flutter is running.

| Environment | Example base URL |
|---|---|
| Android emulator | `http://10.0.2.2:8000` |
| iOS simulator | `http://127.0.0.1:8000` |
| Flutter Web | `http://127.0.0.1:8000` |
| Physical phone | `http://YOUR_COMPUTER_LAN_IP:8000` |

**Important:** On the standard Android emulator, `10.0.2.2` points to your development computer's loopback interface. `127.0.0.1` inside the emulator points to the emulator itself.

Start FastAPI with:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Binding to `0.0.0.0` allows other devices on your local network to reach the development server, subject to firewall and network configuration. Do not expose an unsecured development server to untrusted networks.

# Part 3 — Create the Student Model (10 minutes)

A model represents the structure of a student in Dart.

Create:

`lib/models/student.dart`

```dart
class Student {
  final String? id;
  final String studentCode;
  final String name;
  final int age;
  final String major;
  final int year;
  final bool isActive;

  const Student({
    this.id,
    required this.studentCode,
    required this.name,
    required this.age,
    required this.major,
    required this.year,
    required this.isActive,
  });

  factory Student.fromJson(Map<String, dynamic> json) {
    return Student(
      id: json['id']?.toString(),
      studentCode: json['student_code'] as String,
      name: json['name'] as String,
      age: (json['age'] as num).toInt(),
      major: json['major'] as String,
      year: (json['year'] as num).toInt(),
      isActive: json['is_active'] as bool? ?? true,
    );
  }

  Map<String, dynamic> toJson() {
    return {
      'student_code': studentCode,
      'name': name,
      'age': age,
      'major': major,
      'year': year,
      'is_active': isActive,
    };
  }
}
```

## 3.1 Understand `fromJson()`

Consider this JSON:

```json
{
  "student_code": "ST001",
  "name": "Dara",
  "age": 20,
  "major": "Software Development",
  "year": 2,
  "is_active": true
}
```

This expression:

```dart
Student.fromJson(json)
```

converts a JSON map into a `Student` object.

For example:

```dart
final student = Student.fromJson({
  'student_code': 'ST001',
  'name': 'Dara',
  'age': 20,
  'major': 'Software Development',
  'year': 2,
  'is_active': true,
});
```

You can then access individual properties:

```dart
print(student.name);
print(student.major);
print(student.year);
```

Expected output:

```text
Dara
Software Development
2
```

**Important:** Dart's `jsonDecode()` returns dynamic JSON data. The model performs the conversion into a structured Dart object. If the backend response uses a different field structure, update the model or normalize the response.

# Part 4 — Create the API Service (10 minutes)

The API service is responsible for sending HTTP requests and converting the returned JSON into model objects.

Create:

`lib/services/student_api_service.dart`

```dart
import 'dart:convert';

import 'package:http/http.dart' as http;

import '../models/student.dart';

class StudentApiService {
  final String baseUrl;

  StudentApiService({
    required this.baseUrl,
  });

  Future<List<Student>> fetchStudents() async {
    final uri = Uri.parse('$baseUrl/students');

    final response = await http
        .get(
          uri,
          headers: {
            'Accept': 'application/json',
          },
        )
        .timeout(const Duration(seconds: 15));

    if (response.statusCode != 200) {
      throw Exception(
        'Failed to load students. '
        'HTTP ${response.statusCode}: ${response.body}',
      );
    }

    final dynamic decoded = jsonDecode(
      utf8.decode(response.bodyBytes),
    );

    if (decoded is! List) {
      throw const FormatException(
        'Expected a JSON array of students.',
      );
    }

    return decoded.map((item) {
      if (item is! Map<String, dynamic>) {
        throw const FormatException(
          'Invalid student object in response.',
        );
      }

      return Student.fromJson(item);
    }).toList();
  }
}
```

## 4.1 Understand the HTTP request

```dart
final response = await http.get(uri);
```

This sends an HTTP GET request and waits for the response.

```dart
response.statusCode
```

Returns the HTTP status code, such as `200`, `404`, or `500`.

```dart
jsonDecode(utf8.decode(response.bodyBytes))
```

Decodes the response body from UTF-8 JSON into Dart data.

```dart
decoded.map((item) => Student.fromJson(item)).toList()
```

Converts each JSON object into a `Student` instance.

## 4.2 Why use a separate service?

Separating API requests from UI code makes your project easier to maintain.

```text
lib/
├── main.dart
├── models/
│   └── student.dart
├── services/
│   └── student_api_service.dart
└── screens/
    └── student_list_screen.dart
```

This structure is suitable for a beginner project. Larger applications can introduce repositories, controllers, state management, dependency injection, and dedicated error classes.

# Part 5 — Display Students in Flutter (15 minutes)

Create:

`lib/screens/student_list_screen.dart`

```dart
import 'package:flutter/material.dart';

import '../models/student.dart';
import '../services/student_api_service.dart';

class StudentListScreen extends StatefulWidget {
  const StudentListScreen({super.key});

  @override
  State<StudentListScreen> createState() =>
      _StudentListScreenState();
}

class _StudentListScreenState extends State<StudentListScreen> {
  late final StudentApiService _apiService;

  List<Student> _students = [];
  bool _isLoading = true;
  String? _errorMessage;

  @override
  void initState() {
    super.initState();

    _apiService = StudentApiService(
      baseUrl: 'http://10.0.2.2:8000',
    );

    _loadStudents();
  }

  Future<void> _loadStudents() async {
    setState(() {
      _isLoading = true;
      _errorMessage = null;
    });

    try {
      final students = await _apiService.fetchStudents();

      if (!mounted) return;

      setState(() {
        _students = students;
        _isLoading = false;
      });
    } catch (error) {
      if (!mounted) return;

      setState(() {
        _errorMessage = error.toString();
        _isLoading = false;
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Student Management'),
        actions: [
          IconButton(
            onPressed: _loadStudents,
            tooltip: 'Refresh students',
            icon: const Icon(Icons.refresh),
          ),
        ],
      ),
      body: _buildBody(),
    );
  }

  Widget _buildBody() {
    if (_isLoading) {
      return const Center(
        child: CircularProgressIndicator(),
      );
    }

    if (_errorMessage != null) {
      return Center(
        child: Padding(
          padding: const EdgeInsets.all(24),
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              const Icon(
                Icons.error_outline,
                size: 48,
                color: Colors.red,
              ),
              const SizedBox(height: 12),
              const Text(
                'Could not load students.',
                style: TextStyle(
                  fontSize: 18,
                  fontWeight: FontWeight.bold,
                ),
              ),
              const SizedBox(height: 8),
              Text(
                _errorMessage!,
                textAlign: TextAlign.center,
              ),
              const SizedBox(height: 16),
              ElevatedButton.icon(
                onPressed: _loadStudents,
                icon: const Icon(Icons.refresh),
                label: const Text('Try again'),
              ),
            ],
          ),
        ),
      );
    }

    if (_students.isEmpty) {
      return RefreshIndicator(
        onRefresh: _loadStudents,
        child: ListView(
          physics: const AlwaysScrollableScrollPhysics(),
          children: const [
            SizedBox(height: 180),
            Center(
              child: Text('No students found.'),
            ),
          ],
        ),
      );
    }

    return RefreshIndicator(
      onRefresh: _loadStudents,
      child: ListView.builder(
        physics: const AlwaysScrollableScrollPhysics(),
        padding: const EdgeInsets.all(12),
        itemCount: _students.length,
        itemBuilder: (context, index) {
          final student = _students[index];

          return Card(
            margin: const EdgeInsets.only(bottom: 12),
            child: ListTile(
              leading: CircleAvatar(
                child: Text(student.name[0].toUpperCase()),
              ),
              title: Text(student.name),
              subtitle: Text(
                '${student.studentCode}\n'
                '${student.major}\n'
                'Age: ${student.age} | Year: ${student.year}',
              ),
              isThreeLine: true,
              trailing: Icon(
                student.isActive
                    ? Icons.check_circle
                    : Icons.cancel,
                color: student.isActive
                    ? Colors.green
                    : Colors.red,
              ),
            ),
          );
        },
      ),
    );
  }
}
```

# Part 6 — Troubleshooting (10 minutes)

## Problem 1: Connection refused

**Possible causes:**

- FastAPI is not running.
- The base URL is incorrect.
- The emulator cannot reach the computer.
- A firewall blocks the connection.

**Solutions:**

1. Start FastAPI:

   ```bash
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

2. For the standard Android emulator, use:

   ```dart
   baseUrl: 'http://10.0.2.2:8000',
   ```

3. Test `http://127.0.0.1:8000/docs` in the computer's browser.
4. Check your firewall if using a physical phone.

## Problem 2: Flutter Web reports a CORS error

Configure CORS in FastAPI for the exact origin used by your web frontend.

Example:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",
        "http://127.0.0.1:5173",
    ],
    allow_credentials=False,
    allow_methods=["GET", "POST", "PUT", "PATCH", "DELETE"],
    allow_headers=["*"],
)
```

Add the middleware after creating `app` and before serving requests. Replace the example origins with the actual frontend origin.

CORS is enforced by browsers; it is not the same as a network connection failure.

## Problem 3: HTTP 422

FastAPI returns `422 Unprocessable Entity` when request data fails validation.

Check:

- Field names match the API model.
- Numbers are sent as numbers.
- Boolean values are sent as `true` or `false`.
- Required fields are included in the request.

For the GET `/students` endpoint, inspect the response body and FastAPI logs to identify the cause if validation fails.

## Problem 4: JSON parsing error

If the response contains MongoDB Extended JSON:

```json
{
  "_id": {
    "$oid": "671234567890abcdef123456"
  }
}
```

Do not cast `_id` directly to a `String`. The nested object is not a string.

The model in this lesson reads `id` as an optional string and ignores `_id`. A clean API response with a string `id` is recommended for production.

## Problem 5: Android cleartext HTTP restriction

Local development URLs use `http://`, which may be blocked by Android security configuration.

Use HTTPS in production. If HTTP is required for local testing, permit cleartext traffic only in the development configuration and avoid weakening production security.

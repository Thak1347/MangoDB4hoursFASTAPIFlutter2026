## 4. Configure the MongoDB connection

Create `.env`:

```
MONGODB_URI=mongodb://localhost:27017
MONGODB_DATABASE=university_db
```

This example assumes you have a MongoDB server running locally.

If you use MongoDB Atlas, replace `MONGODB_URI` with your Atlas connection string. Keep your credentials private.

Create `.gitignore`:

```
.venv/
__pycache__/
*.py[cod]
.env
```

## 5. Build the FastAPI application

Create `app/main.py` and add the following code.

```
import osfrom contextlib import asynccontextmanagerfrom typing import Annotatedfrom bson import json_utilfrom dotenv import load_dotenvfrom fastapi import FastAPI, HTTPException, Path, statusfrom pydantic import BaseModel, ConfigDict, Fieldfrom pymongo import AsyncMongoClient, ASCENDINGfrom pymongo.errors import DuplicateKeyErrorload_dotenv()MONGODB_URI = os.getenv("MONGODB_URI")MONGODB_DATABASE = os.getenv("MONGODB_DATABASE", "university_db")if not MONGODB_URI:    raise RuntimeError("MONGODB_URI is missing from .env")@asynccontextmanagerasync def lifespan(app: FastAPI):    client = AsyncMongoClient(MONGODB_URI)    try:        # Verify the database connection.        await client.admin.command("ping")        database = client[MONGODB_DATABASE]        students = database["students"]        # Enforce unique student codes.        await students.create_index(            [("student_code", ASCENDING)],            unique=True,        )        app.state.mongo_client = client        app.state.students = students        yield    finally:        await client.close()app = FastAPI(    title="Student Management API",    description="REST API built with FastAPI and MongoDB",    version="1.0.0",    lifespan=lifespan,)class StudentCreate(BaseModel):    model_config = ConfigDict(str_strip_whitespace=True)    student_code: str = Field(min_length=1, max_length=20)    name: str = Field(min_length=1, max_length=100)    age: int = Field(ge=1, le=120)    major: str = Field(min_length=1, max_length=100)
```

### How the code works

- `load_dotenv()` loads configuration from `.env`.
- `AsyncMongoClient` creates the MongoDB client.
- `lifespan()` connects to the database during application startup and closes the client during shutdown.
- `create_index()` prevents duplicate student codes.
- Pydantic models validate incoming request bodies.
- `serialize_student()` converts MongoDB-specific values such as `ObjectId` into JSON-safe values.
- `HTTPException` returns meaningful HTTP error codes.
- `PATCH` updates only the fields supplied by the client, while `PUT` replaces the editable student data.

## 7. Test the REST endpoints

Use Swagger UI at `/docs`. Expand an endpoint, click Try it out, enter the data, and click Execute.

### Endpoint reference

| Method | Endpoint          | Purpose                     |
| ------ | ----------------- | --------------------------- |
| GET    | `/`               | Check the API               |
| GET    | `/health`         | Check database connectivity |
| POST   | `/students`       | Create a student            |
| GET    | `/students`       | Retrieve all students       |
| GET    | `/students/ST006` | Retrieve one student        |
| PUT    | `/students/ST006` | Replace student data        |
| PATCH  | `/students/ST006` | Update selected fields      |
| DELETE | `/students/ST006` | Delete a student            |

### Test 1 — Create a student

Request: `POST /students`

```
{
  "student_code": "ST006",
  "name": "Lina",
  "age": 20,
  "major": "Software Development",
  "year": 2,
  "is_active": true
}
```

Expected: HTTP `201 Created`, with the saved student document in the response.

### Test 2 — Retrieve all students

Request: `GET /students`

Expected: HTTP `200 OK`, with a JSON array of students.

### Test 3 — Retrieve one student

Request: `GET /students/ST006`

Expected: HTTP `200 OK`, with Lina's record.

If the student does not exist, the API returns HTTP `404 Not Found`.

### Test 4 — Update only the age

Request: `PATCH /students/ST006`

```
{
  "age": 21
}
```

Expected: HTTP `200 OK`. The age changes to 21, while the other fields remain unchanged.

This is the correct endpoint to use for a partial update.

### Test 5 — Delete a student

Request: `DELETE /students/ST006`

Expected response:

```
{
  "message": "Student deleted successfully",
  "student_code": "ST006"
}
```

This permanently removes the matching document. For this practice, delete only test records.

## 8. Common errors and solutions

| Error                             | Likely cause                            | Solution                                      |
| --------------------------------- | --------------------------------------- | --------------------------------------------- |
| `ServerSelectionTimeoutError`     | MongoDB is unavailable                  | Start MongoDB or verify the Atlas connection  |
| `ModuleNotFoundError`             | Missing dependency or wrong environment | Activate `.venv` and install requirements     |
| `422 Unprocessable Entity`        | Invalid request body                    | Check field names, types, and required fields |
| `404 Student not found`           | No matching student code                | Create the record or check the code           |
| `409 Student code already exists` | Duplicate unique key                    | Use a new student code                        |
| `500 Internal Server Error`       | Unexpected application error            | Inspect the terminal traceback                |

CORS note: If you later connect a React or Flutter Web frontend, configure CORS using the frontend's actual origin, such as `http://localhost:5173`. An origin contains the scheme, host, and optional port, but no trailing path.

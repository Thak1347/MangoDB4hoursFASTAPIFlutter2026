# Student Management App — Flutter Frontend

A Flutter application for managing student records through a REST API built with FastAPI and MongoDB. This project is part of my learning journey in Flutter development, API integration, asynchronous programming, and full-stack application development.

## Features

- Display a list of students from the backend API
- Retrieve student information from MongoDB through FastAPI
- Create new student records
- Convert JSON responses into Dart model objects
- Handle asynchronous API requests
- Display loading states and error messages
- Refresh student data
- Support Android emulator and Flutter Web development

## Project Architecture

```text
Flutter Frontend
       |
       | HTTP + JSON
       v
FastAPI Backend
       |
       | PyMongo
       v
MongoDB Database
```

The Flutter application does not connect directly to MongoDB. It communicates with FastAPI, which handles database operations and returns JSON responses.

## 2. Configure the Backend URL

Open:

`lib/services/student_api_service.dart`

Set the API base URL according to the device you are running.

| Target | Base URL |
|---|---|
| Chrome on the same computer | `http://127.0.0.1:8000` |
| Android Studio emulator | `http://10.0.2.2:8000` |
| Physical Android phone | `http://YOUR_COMPUTER_LAN_IP:8000` |

For example, when running on an Android emulator:

```dart
static const String baseUrl = 'http://10.0.2.2:8000';
```

For Chrome on the same computer:

```dart
static const String baseUrl = 'http://127.0.0.1:8000';
```

**Important:** `10.0.2.2` is the Android emulator's special address for reaching the host computer. It is not the correct URL for Chrome running directly on your computer.

## 5. Data Model

The Dart `Student` model represents a student returned by the backend.

| Dart property | JSON field | Type |
|---|---|---|
| `studentCode` | `student_code` | String |
| `name` | `name` | String |
| `age` | `age` | int |
| `major` | `major` | String |
| `year` | `year` | int |
| `isActive` | `is_active` | bool |

Example JSON response:

```json
{
  "_id": "example-mongodb-id",
  "student_code": "ST001",
  "name": "Dara",
  "age": 21,
  "major": "Software Development",
  "year": 3,
  "is_active": true
}
```

The `_id` field is generated by MongoDB and converted to a string by the backend. The Dart model may ignore it if the frontend does not need it.

## 6. API Integration

The `StudentApiService` handles HTTP communication with FastAPI.

| HTTP method | Endpoint | Purpose |
|---|---|---|
| GET | `/students` | Fetch all students |
| GET | `/students/{student_code}` | Fetch one student |
| POST | `/students` | Create a student |
| PUT | `/students/{student_code}` | Replace student fields |
| PATCH | `/students/{student_code}` | Update selected fields |
| DELETE | `/students/{student_code}` | Delete a student |

### Example: Fetch Students

```dart
final response = await http.get(
  Uri.parse('$baseUrl/students'),
);

if (response.statusCode == 200) {
  // Decode the JSON response and map it to Student objects.
} else {
  throw Exception(
    'Failed to load students: ${response.statusCode}',
  );
}
```

### Example: Create a Student

```dart
final response = await http.post(
  Uri.parse('$baseUrl/students'),
  headers: {
    'Content-Type': 'application/json',
  },
  body: jsonEncode(student.toJson()),
);
```

The frontend sends JSON to FastAPI. FastAPI validates the request, performs the database operation, and returns a response.

## 8. Troubleshooting

### `ClientException: Failed to fetch`

For Flutter Web:

- Confirm FastAPI is running.
- Check the API base URL.
- Configure CORS in FastAPI with `CORSMiddleware`.
- Inspect Chrome DevTools → Console for the exact browser error.

### `SocketException` on Android

- Confirm the backend is running.
- Use `http://10.0.2.2:8000` for the standard Android Studio emulator.
- Check Android Internet permission and local HTTP configuration.

### `500 Internal Server Error`

This is a backend error. Read the FastAPI terminal traceback and test `/health/db` to check MongoDB connectivity.

### `422 Unprocessable Entity`

Check the JSON body and ensure that required fields and data types match the backend's Pydantic models.

### `INSTALL_FAILED_INSUFFICIENT_STORAGE`

The Android emulator does not have enough storage to install the application. Free up emulator storage or increase its virtual device storage in Android Studio Device Manager.

### `404 Student not found`

Confirm that the student code exists in the database and that the backend uses the intended database name.
